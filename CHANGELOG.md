# Changelog

## 0.2.0

- Rebuilt the studio in a quieter light theme with restrained accents, smaller tool panels, and more space for the story.
- Removed decorative dot grids, neon glow, and redundant node ID labels.
- Added separate connection ports, obstacle-aware orthogonal routing, distinct return lanes, and collision-aware edge labels.
- Added Flow, Draw on, Pulse, Fade & slide, and Camera focus motion styles with scene-specific speed and intensity.
- Preserved compatibility with v1 project JSON, with sensible defaults for older projects.
- Re-rendered the sample story and README animation.

## 0.1.0

Initial sentence-card editor with playback, scene timing, camera focus, project JSON, local audio, PNG and browser-native WebM export.
